标准 OpenAI 兼容接口

将 TeleAgent 桌面应用的 super-agent API 转换为标准 /v1/chat/completions 和 /v1/models 端点。任何支持 OpenAI API 的工具/SDK（Cursor、ChatBox、LangChain…）无需改代码即可接入。

⚡

零依赖 · 纯 Python

纯标准库实现（http.server + hmac + threading），无任何 pip install。线程安全、SSE 流式输出、自动签名认证，启动即用。监听 0.0.0.0:8088，局域网可访问。

肆
配餐三条铁律
方向性红线，不可违反

① 禁止降档配餐

配餐方向只能平替或升档，绝不能从高档降到低档。出账高于套餐基础费 = 消费能力已达更高档位，应整合升级。

② 溢出即提值信号

实际出账 > 套餐基础费 = 存在溢出（FTTR 月付/收费家庭卡/二宽/增值），溢出费用应整合到更高档位融合礼包。

③ 加人是路径，提值是结果

先看家庭卡是否用满额度，有异网号码就拉进来加卡，加人后自然需要更高档位套餐，提值水到渠成。
